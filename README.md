# SentinelPulse AI – Lightweight AI‑SOC Dashboard

A tiny, offline‑first security‑operations‑center demo built with:

- **Backend** – Flask (Python) – single `app.py`
- **Frontend** – HTML + Tailwind CDN + Chart.js + Lucide icons
- **Data** – In‑memory Python lists (`mock_data.py`)

## Run locally
```powershell
pip install Flask
python app.py
```
Open http://127.0.0.1:5000/ in a browser.
